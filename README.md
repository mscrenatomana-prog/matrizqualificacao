# Matriz de Qualificação — aplicativo Android

Projeto Android que transforma a planilha `Matriz_Qualificacao.xlsx` em um aplicativo mobile.

## O que foi incorporado
- 19 cargos/funções da planilha.
- Regra de experiência por cargo.
- 4 blocos de avaliação: Hard Skills, Comportamental, Corporativo e Criticidade.
- Escala de 1 a 5.
- Pesos da planilha: 0,9 / 0,8 / 0,9 / 0,9.
- Resultado consolidado APROVADO/REPROVADO.
- Salvamento da última avaliação no armazenamento local do aparelho.

## Observação
O ambiente desta conversa não possui o Android SDK/Build Tools e também não permite baixar esses componentes, portanto o APK binário não pôde ser compilado aqui. O projeto está pronto para abrir no Android Studio e gerar o APK.
